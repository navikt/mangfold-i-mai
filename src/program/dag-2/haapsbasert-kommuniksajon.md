Hvordan vi snakker om mangfold og likestilling er helt avgjørende for hva vi kan få til. Som avslutning på det faglige programmet i Mangfold i Mai skal Kristin Dannevig dele sine aller beste verktøy.

Dette er strategisk kommunikasjon for positiv sosial endring. Basert på fem enkle skift kan enkeltpersoner, teams og organisasjoner formulere nye budskap og strategier for god kommunikasjon.

Metoden bygger på forskningsbasert kunnskap om hvordan hjernene våre fungerer. Du kan lese mer om den på https://www.hope-based.com/.
